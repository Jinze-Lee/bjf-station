## 数据管线

```
数据/*.csv  ──校验──> 导入观测数据.py ──> js/observations.js ──> 网页
             (报行号)   (换算/合并/去重)     (OBS_META.source)
                                                    ↑
                              生成示例数据.py ───────┘（source='sample'）
```

两个脚本写同一个文件，靠 `OBS_META.source` 区分；页面据此自动切换提示条，
**导入实测数据后橙色警示条自动消失**，不需要手工改文案。

日常操作见 **`docs/怎么上传数据.md`**（三步：放文件 → 跑脚本 → 刷新）。
数据格式见 **`docs/数据接口规范.md`**。

### 两个容易踩的坑，都做了防护

**① 时区**：CSV 必须带 `+08:00`，页面按 UTC+8 显示（`time.timezoneOffset: -480`）。
配错的话昼夜节律整体平移 8 小时。校验器强制拦缺时区的行；验收测试里有一条
盯着「平均日变化峰值必须落在当地 11–14 时」。

> 用**平均日变化**而不是**单点最大值**来验：液流日变化是平台状的，白天十来个
> 小时几乎等高，噪声会让单点最大值随机落在平台任意位置，用它判时区会误报。

**② 数据结构**：`OBS_FD/OBS_DIA` 用 `[[毫秒时间戳, 值], ...]` 成对结构，
不是「共用时间轴 + 纯数值数组」。后者省 60% 空间，但**假定采样完全规整**——
实测数据必然有掉线、换电池、维护停机造成的空档，成对结构才装得下，
配合 `xAxis.ordinal = false` 才能如实显示空缺而不是把缺口压掉。

### 部分树木没数据时

实测批次常只覆盖部分树木。此时页面会自动：
下拉框里把无数据的树**禁选并标注**、地图上画成**空心圈**、
默认展示的树若无数据则**退回第一棵有数据的**。不会出现「选了没反应」。

## 数据传输示意图

`#network` 区块，可交互的 SVG 动画。

### ⚠️ 关键：两条通路是**完全独立**的

```
通路 B（上）  径向变化仪 ─┐ 自带电池 + 自带无线，每台独立发射
              径向变化仪 ─┼─────── 不经数采，直达 ──────────┐
              径向变化仪 ─┘                                  │
                                                             ├──> 实验室工作站
通路 A（下）  液流探头 ─┐                                    │
              液流探头 ─┼─ 有线 ─> DT80 ─> 无线单元 ))) ────┘
              液流探头 ─┘        (每样点 1 台)
```

**径向变化仪不接入 DT80**，它自带电池与无线模块，每一台都是独立发射节点，
数据直接送到工作站——相当于跳过了中间环节。这一点在图上用
「赤陶色虚线绕过 DT80 从上方直达工作站」表达，并有专门的断言防止画错：

```python
# 验收测试_页面.py
"4o3. 径向链路绕开数采（不与 DT80 方框相交）"   # 逐点采样路径，任一点落进 DT80 包围盒即失败
"4o4. 径向链路终点落在工作站上"
```

- **青蓝点 = 液流信号**（有线流向数采）→ 过 DT80 后变成**浅青方块**（打包上行）
- **赤陶点 = 径向变化信号**（各自独立无线，全程不与青蓝路径合流）
- 每台径向变化仪都画了自己的**电池标识 + 小天线 + 电波**
- 点击任意节点（树 / 径向变化仪 / 数采 / 无线单元 / 工作站）在下方显示说明；
  首屏默认亮的是**径向变化仪**——这是最容易被看漏的一点
- 左上角按钮可暂停/播放；系统开启「减少动态效果」时**默认就是暂停**

**风格取向**：科研图示，不是营销动画。细线、低饱和、匀速直线运动，无缓动无弹跳，
动画只承担「数据在流动」这一个信息，不做装饰性运动。

**实现分工**：
| 文件 | 负责 |
|---|---|
| `index.html` | SVG 结构（连线 `<path>`、节点 `<g class="node">`、`<animateMotion>` 数据包） |
| `css/style.css` | 配色、无线电波与指示灯的 CSS 动画、`prefers-reduced-motion` |
| `js/network.js` | 节点点击、播放暂停、语言切换刷新、**幽灵光标收敛** |

数据包用 SMIL 的 `<animateMotion>` + `<mpath>` 沿路径运动 —— 选它是因为
`svg.pauseAnimations()` / `unpauseAnimations()` 提供了干净的暂停 API，
CSS `offset-path` 在 SVG 子元素上有兼容性坑。

**窄屏**：示意图需要宽度才读得清，所以不等比缩到看不见，而是在容器内横向滚动
（`min-width: 720px`，实测再窄标注就低于 9px 了），并显示滑动提示。
页面本身在 360px 下仍无横向溢出。

**改图示文案**：同样在 `js/i18n.js`，键前缀 `net.*`。

## 中英文切换

**默认英文**，右上角按钮切换，选择存 `localStorage`（键 `bfers-lang-v2`），下次访问沿用。

> 存储键为什么带 `-v2`：默认语言从中文改成英文那次，老访客的 `localStorage` 里还存着
> `'zh'`，会一直盖过新默认值 —— 键升一版即可让旧值作废一次。以后再改默认语言，
> 同样把键升一版，否则改了等于没改。

### 改页面文字

**所有文案集中在 `js/i18n.js`，不要直接改 `index.html`。**
HTML 里只有标记，文字由 i18n 注入：

```html
<h3 data-i18n="about.h3"></h3>              <!-- 替换 textContent -->
<p data-i18n-html="about.p3"></p>           <!-- 段落含行内标签时用这个 -->
```

改文字 → 在 `i18n.js` 的 `zh` 和 `en` 两个字典里改同名键即可。
新增文案 → 两个字典都加同名键，HTML 上打对应的 `data-i18n` 标记。

### 动态内容怎么跟随语言

图表、地图弹窗、信息卡这些由 JS 生成的内容，通过 `Lang.onChange(fn)` 注册回调：

| 模块 | 语言切换时做什么 |
|---|---|
| `tree-info.js` | 重建下拉框、信息卡、树种表、样点卡片 |
| `map.js` | 重建图层控件，刷新全部弹窗内容 |
| `chart.js` | **销毁并重建图表** |

图表为什么要整个重建：Highcharts 的 `rangeSelector` 文案（缩放/从/至）、
日期输入框格式、x 轴与 navigator 的日期格式，都在**建图时渲染定型**，
`redraw()` 改不动，只能重建。代价是丢失当前缩放区间——换语言是低频操作，
可以接受；**当前选中的树会保留**。

### 中文下额外做了什么

- Highcharts 全局 `lang` 换成中文月份/星期名
- 日期格式：轴 `%m月%d日`，输入框 `%Y年%m月%d日`，提示框 `%Y年%m月%d日 %H:%M`
- navigator 刻度单独用 `%m/%d` —— 否则中文月份名会被默认格式拆成 `14 7月` 这种错乱写法
- 正文字号与字重略调（`body[data-lang="zh"]`），避免中文显得过小
- 树种名以「中文名（拉丁名）」呈现，拉丁名保持斜体、中文名不斜体

## ⚠️ 坐标：两层换算，都已处理

野外坐标从手簿到网页要过两道关，两道都会把点标错地方，这里都做掉了。

### 第一关：投影坐标 → 经纬度（在 `工具/生成树木数据.py`）

手簿导出的"北/东"是**投影坐标（米）**，不是经纬度。本站手簿设置为：

| 参数 | 值 |
|---|---|
| 坐标系 | China CGCS 2000 |
| 投影模型 | 高斯投影（Gauss-Krüger） |
| 中央子午线 | 117°00′00″E |
| **长度比** | **1.0** |
| 东向加常数 | 500000.0 m |

对应 **EPSG:4548**。**长度比是关键**：高斯-克吕格是 1.0，UTM 是 0.9996。
两者中央子午线相同、只差这 0.04%，但在 4426 km 的北坐标上会放大成 **1771 m** 偏差。
换算前务必核对这一项。

### 第二关：WGS-84 → GCJ-02（在 `js/map.js`）

高德/腾讯等国内瓦片用 **GCJ-02**（火星坐标系）加密坐标，而上一步算出的是 WGS-84。
直接打点会偏 —— 本站实测偏移 **579 m**。

代码内置转换并在切换底图时自动换算：
- 高德图层 → 转成 GCJ-02 落点
- OpenStreetMap 图层 → 用回原始 WGS-84（实测偏差 0.0 m）

`js/trees.js` 里存的**始终是 WGS-84 原始值**，偏移只在渲染时施加。

### 换坐标时怎么改

改 `工具/生成树木数据.py` 里的 `TREES` / `LOGGERS` 表，重跑脚本即可。
若投影参数不同，改 `EPSG_SRC` 一行。

调试句柄：浏览器控制台可用 `SiteMap.map` / `SiteMap.markers['DT1-BH1-1137']` /
`SiteMap.wgs84ToGcj02(lat, lon)` / `SiteMap.focusTree(id)`。

### 幽灵光标（`#netGhost`）

**要解决的问题**：图里每个节点都能点开说明，但用户看不出来——没有任何「可点」信号。

**做法**：一个半透明指针沿 11 秒周期在三个代表节点上各停一下、点一下，
配合扩散的涟漪；外加工具栏右侧一句明说的提示（`net.clickHint`）。

**收敛**：用户真的动手（点击 / 悬停 / 键盘聚焦任一节点）后，`js/network.js`
给 `.net-wrap` 加 `is-explored`，动画**永久停止**，提示文字降到 0.55 透明度。
提示只在没被理解时才有价值，已经会用了还在演就成了干扰。

坐标写死在 CSS 的 `netGhostPath` 里，与 SVG 节点中心对齐：
径向变化仪 `(126,320)` → 数采 `(474,334)` → 工作站 `(939,306)`。
**改了 SVG 节点位置，这三个数也要跟着改。**

#### 两个踩过的坑，验收里都加了断言

**① 涟漪不能用 `transform-box: fill-box`**（断言 9f）
`.gh-ring` 是 `fill: none` 的 circle，`fill-box` 因此是**空盒**，
`scale()` 缩放空盒等于什么都没有。动画照跑、`getComputedStyle` 一切正常，
只有量 `getBoundingClientRect()` 才发现宽高是 0。
circle 圆心画在 `(0,0)`，而 SVG 的 `transform-origin` 默认就是用户坐标原点，
所以**什么都不加**，`scale()` 自然就是绕自身圆心缩放。

**② 数据包错开出发要用负 `begin`**（断言 9g）
正的 `begin="2.7s"` 在到点之前，SMIL 让元素停在静态位置——
`<circle>` 没写 `cx/cy` 就是 `(0,0)`，于是开头几秒图的左上角有 3 个小圆点像脏点。
负的 `begin="-2.7s"` 表示「动画已经跑了这么久」，元素从第一帧起就在路径上，
错开效果完全一样。

**关于 Reset zoom 按钮**：Highcharts **Stock** 不创建该按钮（`chart.resetZoomButton` 恒为 false），
复位入口是 rangeSelector 的 `All` 按钮。参考站点行为一致，本站保持一致。

**关于地图缩放**：同一样点内树木相距只有 8–20 m，而高德瓦片最高只到 z18。
这里用 `maxNativeZoom: 18, maxZoom: 21` 让 Leaflet 在 z18 以上放大复用瓦片
（画面变糊但位置精确），否则同一样点的 7 棵树会完全叠在一起分不开。

## 换成自己的数据

**不要手写 `js/observations.js`**，走脚本生成（见 `docs/怎么上传数据.md`）。它的结构是
**逐点 `[毫秒时间戳, 值]` 成对数组**：

```js
var OBS_META = { source: 'measured', span: [1753… , 1753…], … };
var OBS_FD   = { 'DT1-BH1-1137': [[1753000200000, 12.3], …], … };  // g m⁻² s⁻¹
var OBS_DIA  = { 'DT1-BH1-1137': [[1753000200000, 19.74], …], … }; // 径向位移 μm
```

键必须与 `js/trees.js` 里的树号一致。序列名称、单位、小数位在 `chart.js` 的
`series` 段改；坐标轴标题在 `yAxis` 段改（`yAxis[0]` = 右轴径向，`yAxis[1]` = 左轴 Fd）。

> **⚠️ 传给 Highcharts 的必须是副本。** `setData` 会接管传入的数组并**就地改写**它。
> 直接把 `OBS_FD[id]` 递进去，切几次树之后存储里的数据就被改坏了（实测某棵树的点数
> 从 304 涨到 435）。`chart.js` 里的 `seriesOf()` 就是干这个的，别绕过它。
> 这个坑在示例数据下**完全看不出来**（所有树点数一样长），只有实测的不等长数据才暴露。

### 改树木清单或坐标

这个检查已经实际揪出过 3 处录入错误，别把它去掉。

## 配色：两套主题，表头可切

**深色森林（默认）** —— 配色取自 treewatch.net 源码实测值，是本站的主视觉。
**暖白纸感** —— 米白底 + 深墨褐字 + 森绿标题 + 赤陶强调。

表头右上角的日/夜按钮切换，选择存 `localStorage`（键 `bfers-theme`）。

### ★ 所有色值集中在 `css/style.css` 顶部，不要在别处写死颜色

```css
:root                       { /* 深色森林，默认 */ }
:root[data-theme="light"]   { /* 暖白纸感，只覆盖与主题相关的变量 */ }
```

最初颜色散在 **178 处硬编码**里，换配色要逐个找。现在收进一组语义变量，
下面 200+ 处规则一律 `var(--x)`，两套主题只是同一组变量的两组取值。

**加新颜色时两套主题都要给值**，否则切到另一套会继承错的颜色。

| 变量 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `#202020` | `#faf8f5` | 页面底 |
| `--surface` | `#262626` | `#ffffff` | 卡片、信息条 |
| `--text` | `#c9c9c9` | `#2d2a26` | 正文（9.8:1 / 13.5:1） |
| `--text-soft` | `#9a9a9a` | `#6b655c` | 表头、dt、图注（5.8:1 / 5.4:1） |
| `--heading` | `#6ca14a` | `#3d5a45` | h3、链接（5.3:1 / 7.2:1） |
| `--accent` | `#f98422` | `#c2703d` | 强调 |
| `--accent-ink` | `#f0a86a` | `#a75c2d` | 强调色**文字**，见下 |
| `--sapflow` | `#1584ec` | `#2c6e8f` | 液流序列 |
| `--radial` | `#f98422` | `#c2703d` | 径向序列 |
| `--dt1/2/3` | `#6ca14a`/`#1584ec`/`#f98422` | `#4a7c59`/`#2c6e8f`/`#c2703d` | 三个样点 |
| `--header-bg` / `--footer-bg` | 森林渐变 | 米白渐变 | 大色块 |
| `--photo-filter` / `--net-scrim` | 压暗 | 提亮 | 背景照处理 |
| `--svg-*` | 一组暗色阶 | 一组浅色阶 | 示意图里树/机箱/连线 |

**为什么 `--accent-ink` 要和 `--accent` 分开**：纯橙在深色底上偏刺眼、在浅色底上
又太亮读不清，所以「强调色文字」单列一档，两套主题各给各的。

**浅色的 `--dt1` 为什么比 `--heading` 亮一档**：它要当地图标记压在高德卫星影像上，
影像本身是绿褐调，用 `#3d5a45` 那种深绿会直接糊进植被里看不见。

### 图表与地图也跟着主题走

两者都不写死颜色：
- `js/chart.js` 的 `palette()` 用 `getComputedStyle` 读 `:root` 变量
- `js/map.js` 的 `plotColor()` 读 `--dt1/2/3`，取不到才回落 `PLOTS[].color`

但**光换变量不够** —— Highcharts 把颜色烤进已生成的 SVG 属性，Leaflet 标记的
颜色也是建 marker 时写死的。所以两者都注册了 `Theme.onChange`：
图表**销毁重建**，地图**逐个 setStyle / setIcon** 并重建图层控件。

### ⚠️ 首屏主题必须在 `<head>` 里定

`index.html` 的 `<head>` 有一段同步内联脚本读 `localStorage` 并设 `data-theme`。
**不能只放在 `js/theme.js` 里** —— 那个文件在 `<body>` 末尾才加载，
届时页面已按默认深色画过一帧，偏好浅色的访客每次都会看到一下深色闪屏。
两处读取逻辑必须一致，改一处要同步改另一处。验收第 10g 条盯着这个。

### 对比度

**两套主题分别逐项量过**（验收 9b / 10c 两组），全部达 WCAG AA，多数 AAA：

```
            h3    导航   正文   脚注   表头   图注   示意图说明  页脚
深色       5.3   12.8   9.8    5.8    5.8    5.8     8.4      5.8
浅色       7.2   16.0  13.5    5.4    5.4    5.4    12.4      5.4
```

> 量对比度时有个坑：取背景色要沿祖先链找**第一个不透明的**，找不到才回落到
> `body`。链走到头拿到 `transparent` 会被当成黑色，把合格的判成不合格 ——
> 第一版检查脚本就是这么把 8 项全报成 FAIL 的，改的是脚本不是样式。

字体仍是 Raleway 300/400/700，已本地化到 `css/fonts/`。

## 已知差异（相对参考站点）

1. **图例**：参考站没有图例（Highcharts Stock 的 `legend` 默认关闭）。
   本站按需求清单加了一个，配色已对齐暖白主题。
   要完全对齐参考站，把 `chart.js` 里 `legend.enabled` 改成 `false`。
2. **Highcharts 版本**：参考站是旧版，本站是 v11.4.8。
   v11 变更的默认值已逐条还原（`lang.rangeSelectorFrom/To`、`inputDateFormat`、
   `xAxis.dateTimeLabelFormats.day`、`scrollbar.buttonsEnabled`）。
3. **量纲**：参考站画整树液流 **L/h**；本站画**液流通量密度 Fd (g m⁻² s⁻¹)**。
   TDP 的直接产物是 Fd，换算成 L/h 必须乘边材面积，而本站尚无边材厚度实测值。
   报 Fd 是诚实做法，不必编造边材面积。补齐边材数据后可改回 L/h。
4. **多树切换**：参考站一页一棵树；本站 20 棵树用下拉框切换，并与地图联动。
5. **数据量级**：参考站是多年实测数据（navigator 显示 2020–2026），
   本站示例数据只有 14 天。
6. **地图**：参考站用 Google Maps（国内不可访问），本站改用 **Leaflet + 高德瓦片**，
   并额外做了 WGS-84→GCJ-02 坐标转换、多图层筛选与图表联动（见上文）。
7. **表头/页脚背景**：参考站用的是自家森林照片。不搬运对方素材，
   本站改用同色调的 CSS 渐变。想换成本站自己的照片，改 `style.css` 里
   `#header-container` / `footer` 的 `background` 即可。
8. **Methods 页面**：参考站的 Methods 页是空的（"coming soon"，从 2014 挂到现在）。
   本站把 Methods 做成首页内的一个区块，写入了实际的方法学说明与 Granier 公式。
