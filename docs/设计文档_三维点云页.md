# 三维点云页设计

状态：已与用户确认，实施中（2026-10-11）。
独立于主站，**新增**，不覆盖任何现有文件。改动前已存档 `_版本备份/v29_三维点云前_20261011`。

## 目标

把 `G:\Forlijinze` 的无人机 LiDAR 彩色点云做成一个**可旋转/缩放/钻入**的三维页面，
叠在**高德卫星底图**上，并标出主站那 **20 棵监测树 + 3 台数采**。

## 硬约束

- **不花钱、不绑卡** → 不用谷歌地图（需绑卡）。全用开源库 + GitHub Pages。
- **国内可访问** → 底图用高德；三维页与主站同域。
- **不拖慢主站** → 三维页独立成页，主站只加一个入口按钮。
- GitHub Pages：仓库 1 GB、单文件建议 < 50 MB、月流量 100 GB（软限制）。

## 数据与处理

- 源：`laser_1_..._转换为Las.las`，8.19 亿点，LAS 1.4 / point format 7（含 RGB），
  EPSG:32650（UTM 50N），范围 ≈ 606×618 m，高程 1172–1353 m。28.1 GB。
- 抽稀：`工具/生成三维点云.py` —— 分块读取 + **体素下采样**（每体素留一个点，保留真彩），
  目标约 800 万–1200 万点。输出到构建目录（不进仓库）。
- 转换：`PotreeConverter 2.1.1`（Windows，已验证可跑）→ Potree 2.0 八叉树（LOD）。
  - 输出目录 `3d/` 进仓库（受 1 GB 限制，目标 < 800 MB）。
- 底图：高德卫星（与主站同一套瓦片；运行时做 WGS-84 → GCJ-02 偏移）。
  - 点云坐标是 UTM 50N，页面用 proj4 与经纬度互转。

## 页面（`3d/index.html`）

- 基于 PotreeConverter `-p` 生成的现成页面，改成：深色森林风格、中英双语、
  高德卫星底图、20 棵树/3 台数采标注（可点开，显示树号/树种/胸径）、返回主站按钮。

## 与主站集成

- `index.html` 的地图区块加一个按钮「查看三维林相 / View 3D forest」，新标签打开 `3d/`。
- 主站其余部分不动。

## 风险与退路

- PotreeConverter 已在本机验证可跑（风险已消）。
- 若八叉树超过仓库容量：加大体素、或把点云瓦片托管到免费大文件托管（如 Hugging Face）。
- 若转换失败：退路是纯 Python 抽稀 + three.js 单文件查看器（无 LOD）。
