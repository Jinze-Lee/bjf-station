## 一、日常更新数据：一条命令

数据更新后想让网站跟着变，跑这个：

```powershell
pwsh -ExecutionPolicy Bypass -File "E:\网页制作\工具\发布更新.ps1"
```

> 用 `powershell` 代替 `pwsh` 也能跑（脚本存成了带 BOM 的 UTF-8，两个版本都认）。

它会依次：列出改动 → 跑 159 项验收 → 提交 → 推送 → 等构建完成并报告。

**推送后约 30 秒到 2 分钟线上生效。** 浏览器没变化就按 `Ctrl+F5` 强制刷新。

几个开关：

| 想干什么 | 加什么参数 |
|---|---|
| 只想看看会改哪些文件，先不推 | `-DryRun` |
| 自己写提交说明 | `-Message "补 7 月下旬数据"` |
| 跳过测试（不建议） | `-SkipTest` |

> **验收不过就不会推。** 这是故意的 —— 线上挂掉比晚发布几分钟严重得多。

完整的数据更新流程（从仪器原始文件开始）见 **`怎么上传数据.md`**。

## 二、关于"实时更新"

先说清楚现在是什么机制，免得有误解。

**现在不是真正的实时。** 网站是一堆静态文件，数据写在 `js/observations.js` 里。
你跑一次上面那条命令，线上就更新一次。**从跑命令到线上生效大约 1 分钟。**

对这个站来说这样够用，因为：

- 数采本来就是**半小时**采一次
- 数据要人工从仪器导出，本来就不是连续流
- 静态站没有服务器要维护，不会半夜挂掉没人管

**什么时候才需要真正的实时？** 如果以后数采能自动把数据传到某台服务器，
那时可以做成「网页定时去后端拉最新数据」。那需要一台常年开机的服务器
（挂靠所里或买云主机），是另一件事，现在不用考虑。

## 三、换个好记的域名（免费）

现在的网址 `jinze-lee.github.io/bjf-station/` 有两个毛病：难记；而且
**`github.io` 这个域名在国内部分地区被 DNS 污染，可能打不开。**

**绑一个自己的域名就能绕过污染** —— 这是换域名最实在的理由，不只是好看。

### 免费方案：is-a.dev

[is-a-dev/register](https://github.com/is-a-dev/register) 是个开源仓库，
给它提一个 PR，就能白拿一个 `你要的名字.is-a.dev` 子域名。

**这些名字都还没被占用**（已核对注册表）：

| 候选 | |
|---|---|
| `bjforest.is-a.dev` | 好记，含义清楚 |
| `bjfs.is-a.dev` | 最短 |
| `donglingshan.is-a.dev` | 地名 |
| `dongling.is-a.dev` | 地名，短一些 |
| `bjfers.is-a.dev` | 台站英文缩写 |
| `sapflow.is-a.dev` | 按内容取 |
| `bj-forest.is-a.dev` / `forest-station.is-a.dev` / `treewatch.is-a.dev` / `bjf.is-a.dev` | 其余可选 |

### 提交步骤

1. 打开 https://github.com/is-a-dev/register，点右上角 **Fork**
2. 在你 fork 出来的仓库里，进 `domains/` 目录，点 **Add file → Create new file**
3. 文件名填 `你选的名字.json`，内容填：

```json
{
    "owner": {
        "username": "Jinze-Lee",
        "email": "lijinze@ibcas.ac.cn"
    },
    "records": {
        "CNAME": "jinze-lee.github.io"
    }
}
```

4. 提交，然后点 **Contribute → Open pull request**
5. 等管理员合并（通常几小时到几天）

### 合并之后要做的

DNS 生效后，回到这个项目跑：

```powershell
# 把 bjforest.is-a.dev 换成你实际拿到的域名
"bjforest.is-a.dev" | Out-File -Encoding ascii -NoNewline "E:\网页制作\CNAME"
powershell -ExecutionPolicy Bypass -File "E:\网页制作\工具\发布更新.ps1" -Message "feat: 绑定自定义域名"
```

然后去仓库 **Settings → Pages**，确认 **Enforce HTTPS** 打上勾
（证书要等几分钟到几小时自动签发，签好之前这个勾可能点不了，等等再来）。

### 这个免费域名的代价，要知道

| | |
|---|---|
| **你不拥有它** | 是别人域名下的一条记录，不能转走、不能续费、随时可能被撤 |
| **父域名出事你跟着完** | `is-a.dev` 哪天在国内被墙，你的站一起打不开，你无能为力 |
| **观感** | `.is-a.dev` 字面意思是"是个开发者"，对中科院台站的官方站点略显随意 |

所以：**先用它跑起来没问题，但把链接写进论文、报告、汇报材料之前，
建议换成自己买的域名**（60–100 元/年）或挂靠所里的 `bjf.cern.ac.cn`。

换域名只需改 `CNAME` 文件一行，站点内容一个字都不用动。

## 四、以后加视频和 PDF

**PDF、操作手册、Word、图片 —— 直接放，没问题。**

在项目里建个 `files/` 目录，把文件丢进去，跑发布命令。
网页里这样链接：

```html
<a href="files/操作手册.pdf">下载操作手册（PDF）</a>
```

**视频要注意 GitHub Pages 的限制**（[官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)）：

| 限制 | 数值 |
|---|---|
| 单个文件 | 建议 < 50 MB（超 100 MB 直接推不上去） |
| 仓库总大小 | 建议 < 1 GB |
| 每月流量 | 100 GB |

一段几分钟的高清视频轻松就上百 MB，**放不进来**。三个办法：

1. **传 B 站，网页里嵌播放器** —— 推荐。国内速度最好，不占仓库空间，
   B 站提供标准的 `<iframe>` 嵌入代码
2. **压到 50 MB 以内**（720p、短片段）后直接放仓库
3. **等挂靠到所里服务器**，那时没有这些限制

> 当前仓库才 4 MB 左右，离 1 GB 还很远，放心加文档和图片。

## 五、以后想换成正式域名

不管是自己买的（如 `bjforest.cn`）还是所里给的（如 `bjf.cern.ac.cn`），做法一样：

1. 在域名的 DNS 管理页加一条 **CNAME 记录**，指向 `jinze-lee.github.io`
2. 改本项目的 `CNAME` 文件为新域名
3. 跑发布命令

**注意：域名如果解析到国内服务器，需要 ICP 备案**（法规要求，个人备案约 1–3 周，
机构备案要单位出面）。解析到 GitHub Pages（服务器在境外）不需要备案，
但访问速度受国际线路影响，时快时慢。

## 六、出问题了怎么办

| 现象 | 多半是 |
|---|---|
| 推送失败，提示连不上 | 代理端口变了。`git -C "E:\网页制作" config --get http.proxy` 看看指向哪，改成当前在跑的端口 |
| 线上没变化 | 没构建完（等 2 分钟），或浏览器缓存（`Ctrl+F5`） |
| 图片裂了、样式丢了 | 大小写。Windows 不区分大小写但 GitHub 服务器区分，`Logo.png` 和 `logo.png` 是两个文件 |
| 图表空白 | 打开浏览器 F12 看 Console 报什么错 |
| 想确认线上是不是真的好使 | `$env:SITE_URL="https://jinze-lee.github.io/bjf-station/"` 然后跑两个验收脚本 |

**想回退到上一个版本：**

```powershell
git -C "E:\网页制作" log --oneline -5      # 找到想回到的那次提交
git -C "E:\网页制作" revert <提交号>        # 生成一次"撤销"提交
git -C "E:\网页制作" push origin main
```

> 用 `revert` 不用 `reset --hard` —— 前者保留历史可再撤销，后者会真的丢掉记录。

## 附：这次为发布改了什么

| 改动 | 为什么 |
|---|---|
| Raleway 字体下载到 `css/fonts/` | 原先引 `fonts.googleapis.com`，国内连不上，会卡到超时才回退系统字体 |
| 加 `.nojekyll` | 让 GitHub 原样提供静态文件，不跑 Jekyll 处理 |
| 加 `.gitignore` | 排除 `_版本备份/`（git 本身就是版本管理）和 `原始数据/`（含未发表记录，仓库是公开的） |
| 加 `.gitattributes` | 统一行尾，避免跨机器出现整篇文件的假 diff |
| 验收脚本支持 `SITE_URL` 环境变量 | 能对线上站跑测试，本地过不等于线上过 |
| 删掉 `docs/待填内容清单.md` | 内容已全部填完，留着会误导 |

**已核实、不需要改的：**

- 高德地图瓦片**没有防盗链**（实测任意 Referer 都正常返回），换域名不用改代码
- 页面代码里没有 `{{ }}` `{% %}`，不会被 Jekyll 误解析
- 引用的资源没有中文文件名（`数据/` 下那几个中文名文件不参与页面运行）
